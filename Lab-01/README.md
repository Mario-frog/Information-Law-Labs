# Лабораторна робота №1

## Тема: Клієнт-серверна взаємодія за протоколом TCP

### Опис
Реалізація TCP-клієнта та сервера мовою Python із використанням модуля `socket`. Сервер приймає текстове повідомлення, переводить його у верхній регістр і повертає клієнту.

### Мета роботи
Дослідити встановлення TCP-з'єднання, передавання та приймання даних між клієнтом і сервером.

### Структура проєкту
- `server.py` — TCP-сервер.
- `client.py` — TCP-клієнт.
- `README.md` — документація.

### Вимоги
Python 3. Сторонні бібліотеки не потрібні.

### Запуск програми
У першому терміналі:
```bash
python server.py
```
У другому терміналі:
```bash
python client.py
```
Введіть повідомлення після запрошення `Enter message:`. Сервер працює за адресою `127.0.0.1:65432`.

### Приклад результату
```text
Enter message: Hello
Server response: HELLO
```
Сервер можна зупинити натисканням Ctrl+C.

### Висновок
Реалізовано обмін текстовими повідомленнями через TCP та досліджено основні операції клієнт-серверної взаємодії.
