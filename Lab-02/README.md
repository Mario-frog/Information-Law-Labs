# Лабораторна робота №2

## Тема: Порівняння транспортних протоколів TCP та UDP

### Опис
Реалізація клієнтів і серверів TCP та UDP мовою Python. Програми вимірюють час отримання відповіді, реєструють результати та демонструють імітацію втрати UDP-пакета.

### Мета роботи
Дослідити особливості TCP та UDP, порівняти час обміну повідомленнями й поведінку за відсутності відповіді.

### Структура проєкту
- `server_tcp.py`, `client_tcp.py` — TCP-сервер і клієнт.
- `server_udp.py`, `client_udp.py` — UDP-сервер і клієнт.
- `results.csv` — журнал результатів.
- `README.md` — документація.

### Вимоги
Python 3. Сторонні бібліотеки не потрібні.

### Запуск програми
Запустіть сервери в окремих терміналах:
```bash
python server_tcp.py
```
```bash
python server_udp.py
```
В інших терміналах запустіть клієнтів:
```bash
python client_tcp.py
python client_udp.py
```
TCP використовує `127.0.0.1:5002`, UDP — `127.0.0.1:5001`.

### Результати роботи
Кожен клієнт виконує серію зі 100 запитів та виводить кількість успішних відповідей і середній час. UDP-клієнт додатково надсилає `__DROP__`, на який сервер навмисно не відповідає. Результати дописуються до `results.csv` (час, протокол, статус, затримка в мілісекундах, повідомлення).

### Висновок
Реалізовано обмін даними через TCP та UDP і підготовлено засоби для порівняння затримок та обробки втрати відповіді.
