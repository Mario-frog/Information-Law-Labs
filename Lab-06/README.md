# Лабораторна робота №6

## Тема: Дослідження систем виявлення та запобігання вторгненням (IDS/IPS)

### Опис

Налаштування Suricata для моніторингу мережевого трафіку, виявлення загроз та блокування підозрілих пакетів. Дослідження проводиться в ізольованій лабораторній мережі між власними віртуальними машинами.

### Мета роботи

Дослідити принципи роботи IDS та IPS, налаштувати локальні правила Suricata, перевірити їх спрацювання під час контрольованих експериментів та проаналізувати журнали подій.

### Функціональні можливості

- Виявлення сканування портів за TCP SYN-пакетами.
- Виявлення SYN flood на вебсервіс.
- Виявлення SQL-ін'єкцій за шаблонами UNION SELECT та OR 1=1.
- Виявлення User-Agent інструмента sqlmap.
- Виявлення тригера бекдору vsftpd 2.3.4 та підключень до порту 6200.
- Моніторинг трафіку в режимі IDS та фільтрація в режимі IPS через NFQUEUE.
- Аналіз журналів fast.log та eve.json.

### Вимоги

- Ubuntu із Suricata та jq.
- Kali Linux для контрольованих експериментів.
- Ізольована host-only мережа 192.168.56.0/24.
- DVWA та vsftpd 2.3.4 або відповідна навчальна VM для експериментів.
- Права адміністратора для налаштування мережі та Suricata.

### Налаштування та запуск

Клонування репозиторію:

```bash
git clone https://github.com/Mario-frog/Information-Law-Labs.git
cd Information-Law-Labs/Lab-06
```

Встановлення на захищеній машині:

```bash
sudo apt update
sudo apt install -y suricata jq
sudo suricata-update
sudo cp local.rules /etc/suricata/rules/local.rules
```

У конфігурації `/etc/suricata/suricata.yaml` налаштуйте HOME_NET відповідно до лабораторної мережі та додайте `local.rules` до списку `rule-files` разом із `suricata.rules`. Перевірте, що шлях до каталогу правил відповідає розташуванню файлів.

Перевірка конфігурації:

```bash
sudo suricata -T -c /etc/suricata/suricata.yaml
```

Запуск IDS (замініть `enp0s8` на інтерфейс лабораторної мережі):

```bash
sudo suricata -c /etc/suricata/suricata.yaml -i enp0s8
```

Перегляд журналу:

```bash
sudo tail -f /var/log/suricata/fast.log
```

Повна інструкція з налаштування IPS, проведення експериментів та аналізу результатів: [run_lab6.md](run_lab6.md).

### Результати роботи

Передбачено перевірку спрацювання семи локальних правил Suricata під час контрольованих експериментів. Правила з дією `alert` реєструють події, а правила `drop` у режимі IPS можуть блокувати відповідний трафік. У режимі IDS трафік не блокується.

Для аналізу використовуються журнали `fast.log` та `eve.json`. Фактичні результати залежать від конфігурації мережі, режиму роботи Suricata та тестового трафіку.

### Висновок

Лабораторна робота демонструє застосування Suricata для виявлення мережевих загроз та запобігання вторгненням. Локальні правила дозволяють дослідити реакцію системи на характерні ознаки сканування, DoS, SQL-ін'єкцій та експлуатації вразливостей. Аналіз журналів допомагає оцінити спрацювання правил і відмінності між режимами IDS та IPS.

> Усі експерименти виконуються виключно у власній ізольованій лабораторній мережі. Навчальні вразливі сервіси не слід відкривати в Інтернет.
