# Лабораторна робота №4

## Тема: Криптографічний захист мережевих даних та SSH-тунелі

### Опис
Програмна демонстрація AES-256-GCM, RSA-PSS із SHA-256 та HMAC-SHA256. Окрема інструкція описує налаштування SSH-тунелів між двома віртуальними машинами.

### Мета роботи
Дослідити шифрування, цифровий підпис, контроль цілісності повідомлень та захищене перенаправлення мережевого трафіку через SSH.

### Структура проєкту
- `crypto_lab4.py` — криптографічна демонстрація.
- `requirements.txt` — залежності.
- `SSH_інструкція.md` — налаштування SSH-тунелів.
- `README.md` — документація.

### Вимоги
Python 3 та бібліотека `cryptography`. Для SSH-практики — дві доступні одна одній VM з Ubuntu/Debian та OpenSSH.

### Встановлення залежностей
```bash
python -m pip install -r requirements.txt
```

### Запуск програми
```bash
python crypto_lab4.py
```

### Функціональні можливості
- AES-256-GCM: шифрування, розшифрування та виявлення зміни шифротексту.
- RSA-PSS: генерація 2048-бітного ключа, підписування та перевірка повідомлення.
- HMAC-SHA256: перевірка цілісності оригінального та зміненого повідомлень.

### SSH-тунелі
Докладні команди наведено у [SSH_інструкція.md](SSH_інструкція.md). Розглянуто локальне (`-L`), віддалене (`-R`) та динамічне (`-D`) перенаправлення портів. Виконуйте налаштування лише на власних VM або з дозволу адміністратора.

### Результати роботи
Програма демонструє успішне розшифрування, перевірку підпису оригінального повідомлення та відхилення змінених даних. SSH-інструкція дозволяє окремо перевірити три типи тунелів.

### Висновок
Досліджено криптографічні механізми захисту даних та підготовлено інструкцію для практичного налаштування SSH-тунелів.
