# Лабораторна робота №3

## Тема: Дослідження протоколу ARP

### Опис
Програма для ARP-сканування локальної мережі, побудови графа відповідностей IP–MAC та виявлення змін MAC-адрес. Передбачено також формування ARP-запиту вручну через raw socket у Linux.

### Мета роботи
Дослідити механізм визначення MAC-адрес за IP-адресами та ознаки підозрілих змін ARP-відповідностей.

### Структура проєкту
- `arp_lab3.py` — основна програма.
- `requirements.txt` — залежності.
- `README.md` — документація.

### Вимоги
Python 3, Scapy, Matplotlib, NetworkX. Для мережевих режимів можуть знадобитися права адміністратора; у Windows — Npcap. Режим `raw` підтримується лише в Linux.

### Встановлення залежностей
```bash
python -m pip install -r requirements.txt
```

### Запуск програми
Демонстрація на синтетичних даних без передавання пакетів:
```bash
python arp_lab3.py demo
```
Сканування власної локальної підмережі (замініть адресу на свою):
```bash
python arp_lab3.py scan 192.168.1.0/24 --graph arp_network.png
```
Моніторинг ARP-пакетів протягом 30 секунд:
```bash
python arp_lab3.py monitor --seconds 30
```
Довідка щодо ручного ARP-запиту в Linux:
```bash
python arp_lab3.py raw --help
```

### Результати роботи
Сканування виводить IP- та MAC-адреси активних пристроїв і створює `arp_network.png`. Моніторинг повідомляє про появу нової MAC-адреси для вже відомої IP-адреси. Такі зміни не завжди є атакою та потребують перевірки.

Використовуйте мережеві режими лише у власній мережі або з дозволу адміністратора. Сканування обмежено приватними підмережами до 256 адрес.

### Висновок
Реалізовано ARP-сканування, візуалізацію відповідностей IP–MAC і демонстрацію виявлення змін адрес.
